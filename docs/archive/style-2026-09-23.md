# GymCompanion — Règles de Style (Nothing OS)

## 1. Palette (Nothing — marque officielle)
- `NothingBlack` / `Background` : `#000000` — fond écran (OLED)
- `NothingDeep` : `#111111` — surface carte / FAB
- `NothingDark2` : `#1A1A1A` — surfaces élevées (inputs)
- `NothingBorder` / `Mid` / `Strong` : `#222222` / `#333333` / `#4D4D4D` — bordures solides (aucune alpha sur bordures)
- `NothingWhite` : `#FFFFFF` — texte affichage uniquement
- `NothingGrey1` / `2` / `3` : `#DCD7D2` / `#B1B3B3` / `#666666` — texte principal / secondaire / désactivé
- `NothingRed` (`#C8102E`) — statut : streak, aujourd'hui, erreurs, suppression
- `NothingYellow` (`#FFC700`) — intelligence : IA, scan, favoris
- `NothingBlue` (`#002F6C`) — progress : anneaux, barres, remplissages uniquement

## 2. Cartes & Widgets (`NothingCard` / `GlassCard` / `WidgetForm`)
- Surface : `NothingDeep` (`#111111`), angles `RoundedCornerShape(24.dp)`
- Bordure : AUCUNE bordure sur la carte elle-même ; bordure uniquement sur éléments interactifs internes (`NothingBorderMid`, `RoundedCornerShape(8.dp)`)
- Ombre : 0 (pas d'ombre, design plat Nothing)
- Padding interne carte (`NothingCard`) : `14.dp`
- Padding externe `WidgetForm` : `horizontal = 8.dp` (fixe, ne jamais changer)
- Entre widgets dans une `LazyColumn` : `Spacer(Modifier.height(10.dp))` (uniforme)

## 3. Nombre d'Or (φ ≈ 1.618)
- Utilisé dans la mise en page des widgets symétriques (duals arcs, colonnes)
- Quand un `Row` contient deux éléments principaux, utiliser `Modifier.weight(1f)` pour chacun si symétrique ; `GoldenRatio` (1.618) et `GoldenRatioInverse` (0.618) uniquement quand un déséquilibre visuel est voulu (ex. arc graisse vs muscle avant correction → corrigé en `1f`)

## 4. Typographie (3 familles — jamais mélanger mécaniquement)
- **Doto** (dot-matrix) : `NumText` pour nombres ≥ 24 sp (`DOT_MIN_SP`)
- **Space Mono** : fallback `NumText` < 24 sp ; toutes les étiquettes `NLabel` (ALL CAPS, `letterSpacing = 2.4.sp`, `size = 9.sp`)
- **Space Grotesk** : corps / titres (`Text` standard)
- Une seule accentuation par écran (`fontFamily = LocalNumericFont.current` uniquement sur le nombre héros)

## 5. Centrage & Alignement
- `ArcStat` : `Box(Modifier.size(92.dp), contentAlignment = Alignment.Center)` — le `NumText` DOIT avoir `Modifier.align(Alignment.Center)` explicit
- `CompactStat` : `Column(horizontalAlignment = Alignment.CenterHorizontally)` avec `NumText` centré
- Tous les `Row` avec `Arrangement.SpaceEvenly` doivent utiliser `verticalAlignment = Alignment.CenterVertically`
- Quand deux éléments sont côte à côte (fat / muscle), utiliser `Modifier.weight(1f)` des deux côtés pour centrage parfait

## 6. FAB (Boutons Flottants)
- Style unifié via `Components.kt` : `StandardFAB` (56 dp, `RoundedCornerShape(14.dp)`) et `SmallFAB` (44 dp, `RoundedCornerShape(10.dp)`)
- Couleurs : `NothingDeep` surface, bordure `NothingBorderMid`, icône `NothingWhite` (ou `NothingYellow` pour actions IA)
- Jamais de FAB sans bordure — toujours `.border(1.dp, NothingBorderMid, ...)`

## 7. Performance
- Tout graphique animé (`SegmentedArc`, `ArcProgress`) doit utiliser `remember(progress)` ou `derivedStateOf` pour éviter la relance de l'animation à chaque recomposition du `LazyColumn`
- Toujours fournir `key` aux items `LazyColumn` / `LazyRow` (`key = { ... }`)
- Éviter `LazyRow` sans `contentPadding` cohérent (`horizontal = PAD` si nécessaire)

## 8. Cohérence Code
- `PAD` (24.dp) : uniquement pour le padding des textes hors-widget (headers d'écran, sections)
- `WidgetForm` utilise `Modifier.fillMaxWidth()` + `padding(horizontal = 8.dp)` — ne JAMAIS ajouter un autre `padding(horizontal = PAD)` au contenu du widget (cela casse la cohérence)
- `VDivider` doit être centralisé dans `Components.kt` (hauteur et padding paramétrables)
- `NLabel` : toujours `fontFamily = MonoFamily`, `fontWeight = Normal`, `maxLines = 1`
