## Build & Run

Open the project root in **Android Studio Ladybug or newer**. Gradle syncs automatically.

```bash
# Assemble debug APK
./gradlew assembleDebug

# Install on connected device/emulator
./gradlew installDebug

# Run all tests
./gradlew test

# Lint
./gradlew lint
```

Minimum SDK: 28 — always test on API 28+ emulators.

## Architecture

**MVVM + Repository + Hilt DI**, fully reactive with Kotlin `Flow` / `StateFlow`.

```
data/model/     → Room @Entity classes (FoodEntry, WorkoutSession, StepRecord, BodyRecord, Streak, DailyGoal)
data/db/        → Room DAOs returning Flow<T> + AppDatabase
data/repository/GymRepository.kt → single source of truth, injected @Singleton
viewmodel/      → one HiltViewModel per screen, exposes StateFlow<UiState>
ui/screens/     → one Composable screen per tab (dashboard, nutrition, workout, steps, body)
ui/components/  → shared Compose components (GlassCard, CircularProgressCard, MacroBar, StreakBadge…)
ui/theme/       → Material 3 dark color scheme (Theme.kt) + typography (Type.kt)
ui/navigation/  → sealed Screen class + bottomNavItems list
```

**DI wiring:** `GymCompanionApp.kt` holds `@HiltAndroidApp` and the `@Module` that provides the Room database and all DAOs. ViewModels use `@HiltViewModel` + `@Inject constructor`.

**Navigation:** single `NavHost` in `MainActivity.kt` with fade transitions. Bottom nav is a custom floating pill built from `NavigationBar` + `GlassCard` styling — not a standard `NavigationBar` scaffold placement.

**Streak logic** is atomic SQL in `StreakDao.recordActivity()` (called via `GymRepository.recordStreakActivity(type)`) — increment/reset/insert in a single transaction, no read-modify-write races.

**Date handling:** ViewModels that show "today" data use `common.todayFlow()` (re-emits at midnight) — never capture `LocalDate.now()` at ViewModel creation.

## Key design tokens (Nothing OS — official brand palette)

Dark mode only. Colour lives ONLY on data values; labels/backgrounds stay monochrome.

| Token | Value | Usage |
|---|---|---|
| `NothingBlack` / `Background` | `#000000` | Screen background (OLED) |
| `NothingDeep` | `#111111` | Card/FAB surface |
| `NothingDark2` | `#1A1A1A` | Raised surface (inputs) |
| `NothingBorder/Mid/Strong` | `#222222`/`#333333`/`#4D4D4D` | Borders (solid greys, no alpha) |
| `NothingWhite` | `#FFFFFF` | Display text only |
| `NothingGrey1/2/3` | `#DCD7D2`/`#B1B3B3`/`#666666` | Primary/secondary/disabled text |
| `NothingRed` | `#C8102E` (N-Red) | Status: streak, today, errors, delete |
| `NothingYellow` | `#FFC700` (N-Yellow) | Intelligence: AI, scan auto-fill only |
| `NothingBlue` | `#002F6C` (N-Blue) | Progress rings/bars/fills only |

All content cards use `NothingCard` (`ui/components/Components.kt`, alias `GlassCard`) — flat surface + solid border, no gradients, no shadows. **Never hardcode hex colours outside `Theme.kt`.**

Typography: Doto (dot-matrix) for hero numbers ≥ 24sp only (`NumText` falls back to Space Mono below), Space Mono for ALL CAPS labels + small data, Space Grotesk for body/headings. One accent moment per screen.

## Adding a new screen

1. Add a `Screen` object in `ui/navigation/Navigation.kt` and append to `bottomNavItems`.
2. Create `ui/screens/<name>/<Name>Screen.kt` with a `@Composable` function.
3. Create `viewmodel/<Name>ViewModel.kt` annotated `@HiltViewModel`.
4. Register the `composable(Screen.<Name>.route)` in the `NavHost` inside `MainActivity.kt`.
5. Add any new DAOs/entities: update `AppDatabase.kt` entities list, bump `DB_VERSION`, and add a real migration in `Migrations.kt` (destructive migration is NOT used).
