# Scripts historiques

`clean_div.py`, `clean_spacers.py`, `fix_nutrition_spacer.py` et `fix_nutrition_spacer2.py` sont conservés à l'identique. Ils ont servi à des retouches ponctuelles et contiennent des chemins Windows absolus ainsi que des remplacements textuels globaux.

Ne pas les lancer comme une routine de maintenance. Pour une nouvelle correction, modifier les composants concernés et relire le diff. Leur déplacement n'ajoute aucune commande au build Android.
