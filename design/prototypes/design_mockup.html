05 — Corps
Plan de design — problèmes identifiés & solutions
PROBLÈME 01
Fond trop brutal

Pure black (#000000) = absence totale de profondeur. Le cerveau ne distingue pas les niveaux d'élévation. Chaque élément est "à plat" sur rien.

SOLUTION

Fond #0A0A14 (near-black avec micro tinte bleue). Cards à #10101C. La différence est subtile mais crée une hiérarchie réelle.

PROBLÈME 02
Couleurs trop étouffées

Les accents sur fond noir pur perdent leur vibrance. Les glows n'ont rien à éclairer. Le résultat est terne.

SOLUTION

Légèrement plus saturés : Purple #8B7FFF, Teal #00E5B8 + filter: drop-shadow(glow) sur les SVG arcs.

PROBLÈME 03
Hiérarchie typographique absente

Tout le monde a la même taille. Le chiffre "1847 kcal" et le label "CALORIES" ont le même poids visuel.

SOLUTION

Les données hero passent à 56–72px. Labels = 9px, letter-spacing 3px. Contraste de taille 8:1 minimum entre hero et label.

PROBLÈME 04
GlyphBar trop discret

6dp de haut, presque invisible. Censé être l'élément signature — il est ignoré.

SOLUTION

Hauteur à 8dp, gap à 3px, segments pleinement colorés (pas d'alpha). Version mini (3dp) pour les cartes de liste.

PROBLÈME 05
Cards sans identité

Toutes les cards ont la même bordure dim, le même padding. Hero card = list card. Aucun moyen de savoir ce qui est important.

SOLUTION

3 niveaux : Hero (gradient bg + glow ambiant), Widget (bg card + border mid), List item (bg card + border dim).

PROBLÈME 06
Dashboard sans moment fort

La page principale est une liste de widgets identiques. Pas de hero visuel, pas d'accroche émotionnelle.

SOLUTION

Widget calorie en hero plein-largeur avec arc double + chiffre géant. Streak + corps en widgets demi-largeur. Hiérarchie claire.

❌ Avant — Ce qui ne marche pas
🎨Fond #000000 pur → plat, sans profondeur, harsh sur OLED
📝Tous les textes à la même taille → pas de hiérarchie
📊GlyphBar 6dp, alpha 10% → invisible
🃏Cards identiques pour hero et list items
✨Accents sans glow → couleurs mortes sur noir
🏠Dashboard = liste plate sans moment fort
🔤GlyphDecoration header bar — trop petit, ignoré
✅ Après — Solutions appliquées
🎨Fond #0A0A14 (blue-black) + cards #10101C → profondeur naturelle
📝Hero 56–72px mono / Labels 9px uppercase → contraste 8:1
📊GlyphBar 8dp, segments pleinement colorés, version mini 3dp
🃏3 niveaux : Hero (gradient+glow), Widget, List
✨drop-shadow glow sur arcs SVG → accents qui respirent
🏠Dashboard hero calorie plein-largeur + widgets 50/50
🔤Texte secondaire #AAAACC (blue-tinted) → plus doux que gris pur
