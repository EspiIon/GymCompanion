Composant
Arc segmenté — spécification SVG

Stroke en dasharray discret pour imiter les LEDs Nothing. Pas de strokeLinecap round.

/* Track */
stroke-dasharray: 4 2
pathLength: 270
stroke-dashoffset: -90
stroke-linecap: butt

/* Progress (clip-path % = 100-progress) */
clip-path: inset(0 26% 0 0)

/* Arc ouverture : 270°, départ bas-gauche */
rotate(-135deg) sur le SVG
  • stroke-width: 8dp (small) · 10dp (medium) · 12dp (large)
  • Jamais stroke-linecap:round
  • Track alpha : 10% de la couleur accent
  • Aucun shadow, aucun glow
Architecture
Hiérarchie des widgets
HERO (pleine largeur)

Chiffre principal ≥ 36px · Arc segmenté · GlyphBar H-8/12.
Usage : calorie dashboard, ring steps plein écran.

DATA (demi-largeur)

Chiffre 20-28px · GlyphBar H-8.
Usage : streak, pas résumé, résumé séances.

LIST (item)

Chiffre 12-14px · GlyphBar H-3 optionnel.
Usage : food rows, session rows, historique.

Règles impératives
Nothing OS — 8 lois
⬛
Fond = #000000 pur. Jamais de tinte bleue ni de dégradé sur les surfaces.
🎨
Couleur sur data seulement. Le fond d'une card, d'un header ou d'un label reste noir ou gris.
✏️
Zéro gradient. background: linear-gradient → interdit partout.
🔲
Zéro shadow/glow. box-shadow, text-shadow, drop-shadow → interdits.
🔤
Monospace pour tout chiffre. Space Mono sur toute valeur numérique sans exception.
↔
Labels = UPPERCASE + letter-spacing ≥ 3px. Aucun label en casse mixte.
⠿
Arc = segments discrets. stroke-dasharray sur pathLength=270. Jamais un arc lisse.
▣
GlyphBar = élément principal, pas décoratif. Toujours visible, toujours en rapport avec une donnée.
❌ Violations précédentes
🟥Fond #0A0A14 avec tinte bleue — pas Nothing OS
🟥box-shadow glow sur les arcs SVG
🟥background: linear-gradient sur les cards hero
🟥GlyphBar 5-6dp, invisible — rôle décoratif seulement
🟥Texte secondaire #AAAACC "blue-tinted grey"
🟥Arc = trait lisse continu (pas segmenté)
🟥FAB coloré plein (fond violet)
✅ Standard Nothing OS appliqué
🟩Fond #000000 strict, surface #0D0D0D
🟩Zéro shadow/glow — forme définie par la bordure seule
🟩Zéro gradient — background monochrome uniquement
🟩GlyphBar H-12/8/5/3 — 4 tailles, rôle fonctionnel
🟩Texte secondaire #999999 — gris neutre pur
🟩Arc = stroke-dasharray discret (pathLength 270)
🟩FAB = fond noir, bordure blanche, icône blanc
